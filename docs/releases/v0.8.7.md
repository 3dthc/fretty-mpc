# Fretty v0.8.7

## What's new
- **Instruments browser card:** Fretty now shows as its own card in Sounds > INSTRUMENTS. Tapping it opens the plugin's preset list (after the restart the installer does).

## Fixed
- **Preset name on the MPC:** picking a preset on the BROWSE page now changes the preset name MPC shows (and its PRESET menu's selection) to that preset. Before, the sound changed but the name stayed on the last preset picked in MPC's own menu. The same holds in the desktop VST3 and Audio Unit.
- **MPC's PRESET list closing or jumping while you play:** every note made Fretty ask MPC to redraw its whole screen (to refresh a chord name that isn't shown anywhere), and each redraw closed or moved the open PRESET list. Playing no longer redraws the screen; the fretboard still animates.
