# Fretty v0.8.3

## Presets

- Expanded the preset catalog from 50 to 110 presets.
- Organized presets into 10 categories, with 11 presets per category.
- Alphabetized categories and preset names for easier browsing in the MPC PRESET menu.
- Presets continue to leave THEME and PERFORM settings unchanged.

## Testing

The updated preset ordering has been installed and checked on an MPC. The release workflow builds a fresh package and runs the host test; test the resulting draft-release ZIP on the device before publishing.
