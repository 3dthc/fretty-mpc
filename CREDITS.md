# Credits

## Samples
Archtop plays **Shinyguitar** by Karoryfer Lecolds (D. Smolken): an archtop guitar recorded through its magnetic
pickup and a microphone at once, four velocity layers, four round robins, release and fret noises, muted strings and
body knocks.

- Source: https://github.com/sfzinstruments/karoryfer.shinyguitar (commit `57243cc`)
- License: **CC0 1.0 Universal** (public domain dedication), so the samples can be redistributed inside this plugin.

`tools/pack_samples.py` repacks only the WAV files and the SFZ key/velocity mapping. Shinyguitar's GUI artwork, photos
and signed Sforzando bank file are not used.
